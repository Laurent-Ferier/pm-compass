class

The "Task Graph" leaf. Loads every Task/Project and renders them as a cytoscape.js dependency graph with drill-down into a project and drag-to-connect dependencies; hands off editing to the modals, and re-parenting to MoveTargetModal via its own context menu (this view does not extend BaseTabView).

abstract

Shared plumbing for the three tabs: collapsible sections, the project-task row renderer (priority ribbon, status badge, deadline label), the subtask/move/delete context menu, the promote-to-project-task flow shared by the Inbox and the Dashboard, and the hand-off into TaskGraphView when a row is clicked. 05

Models & data

no Obsidian UI base — file wrappers & value objects
DayTask
class

Value object for one checklist line: title, checked, tags, four date fields (created/completed/due/scheduled/start), priority, and any indented sub-lines. Parsed from and re-serialized to a single raw markdown line — never constructed directly.

fieldstitle, checked, tags, createdAt, dueDate, priority, rawLine, subLines staticparse(line) · create(title, date)
produced/consumed by → DayMarkdownFile aggregated by → WeekSummary rendered by → DashboardView, InboxView
DayMarkdownFile
class

The sole read-modify-write gateway for one daily note's checklist lines — parse, add, remove, check/uncheck, edit a title or sub-lines, reconcile recurring habits. Serializes concurrent writes to the same path behind a per-file lock.

fieldsfilePath methodsparseTasks() · addTask() · remove() · checkTask() · reconcileRecurringHabits() staticensure(app, date)
produces/consumes → DayTask[] used by → day-task-actions, on behalf of Dashboard/Inbox/PMCompassPlugin
ProjectFile
class

Typed read/update/create of one project root note. Owns its frontmatter (title, color, icon) and its taskIds + ## Tasks list of root-level tasks — a denormalized copy this plugin never reads back (the tree comes from parentId), maintained so obsidian-pm's own board stays correct. create() writes that plugin's full schema, including fields nothing here consumes. Analogous to DayMarkdownFile but for a single-record file instead of a multi-task list.

fieldsfilePath methodsreadMetadata() · update(data) · addTaskLink() · removeTaskLink() staticcreate(app, opts)
read/updated by → ProjectModal created/linked by → promoteChecklistItem, moveTask links via → child-links (addChildLink/removeChildLink)
ProjectTaskFile
class

Typed read of one task note's subtask ids and description, and patch of its status/priority frontmatter — including side effects like auto-stamping a completed date. Analogous to DayMarkdownFile but per-task instead of per-day.

fieldsfilePath methodsreadSubtaskIds() · readDescription() · patchField(field, value) · update(data) · setBodyPrefix() · addSubtaskLink() · removeSubtaskLink() · delete() staticcreate(app, opts)
read/updated by → TaskModal, TaskGraphView, BaseTabView (quick-edit dropdowns) created by → promoteChecklistItem · relocated by → moveTask links via → child-links (addChildLink/removeChildLink)
